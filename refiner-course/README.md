# 练知 (Refiner) — AI 学习助手课程案例

> 一门面向零基础学员的 AI 编程课案例。学员通过两天课程，跟随 AI 协作完成一个支持 Web + 桌面端 + 移动端的 AI 学习助手，并了解全流程开发与商业化路径。

---

## 一、产品概述

### 名称

| 语言 | 名称 | 说明 |
|------|------|------|
| 中文 | **练知** | "练习知识"——把笔记炼成可练可考的知识 |
| 英文 | **Refiner** | "炼金者"——杂乱的笔记经过提炼成为有价值的知识 |

### 一句话描述

> 把学习笔记丢进去，AI 帮你提炼成知识点卡片 + 出题测试 + 评分反馈的智能学习工具。

### 核心闭环（1.0）

```
用户粘贴笔记 → 结构化大纲 → 知识卡片（复习） → AI 出题 → 答题 → AI 评分+反馈
```

### 产品定位

- **不是** Quizlet/Anki 的替代品
- **是** 一个"AI 把个人笔记变成专属题库"的轻量学习工具
- 差异化：**本地优先**（数据只存用户设备）、**定制化**（针对自己的笔记出题）

## 三、提示词管线（4 组核心 Prompt）

详见 `prompts/` 目录：

| 文件 | 步骤 | 输入 | 输出 | 耗时 |
|------|------|------|------|------|
| `01-notes-structurer.md` | P1：笔记结构化 | 原始笔记 | 结构化大纲 JSON | 3–8s |
| `02-knowledge-cards.md` | P2：知识卡片 | 知识点 JSON | 卡片 JSON | 2–5s × N |
| `03-quiz-generator.md` | P3：出题 | 知识点列表 | 练习题 JSON | 3–8s |
| `04-answer-evaluator.md` | P4：评分 | 题目+答案 | 评分反馈 JSON | 2–4s |

调用关系：

```
P1 ──串行──→ P2 ──独立──→ P3 ──每道题独立──→ P4
                     │
                     └── 也可单独调用（选中特定知识点出题）
```

## 四、技术栈

| 层 | 技术 | 原因 |
|----|------|------|
| 框架 | Vue 3 + Vite | 轻量、零基础友好、可过渡到 Tauri |
| 样式 | Tailwind CSS | 快速出好看的 UI |
| AI | DeepSeek API（统一 key） | 便宜（单次 ~1分钱）、国内直连、OpenAI 兼容 |
| 存储 | localStorage | 1.0 不接服务器 |
| 部署 Web | Vercel / Netlify | 秒级部署，零配置 |
| 跨端 | Tauri 2（2.0 引入） | 零业务改动封装原生 App |

### 为什么 1.0 不做 Tauri

- 1.0 锁死 Web，避免学生被 Rust 环境装到劝退
- 第 1 天最后阶段演示 Tauri 封装效果，**业务代码一字不改**就变成原生 App
- 第 2 天让学生体验/演示打包过程

### 为什么 1.0 不接服务器

- 零基础学员调不动后端 bug
- 登录注册至少吃掉 30 分钟
- "本地优先"反而是差异化卖点（"你的笔记只在你电脑上"）
- 商业化前再加 Cloudflare Workers + Supabase 即可

- 全流程必须在 Mac 上用 Xcode 操作
- 20 个学生里 iPhone + Mac 用户可能不到 10%

## 六、成本预估

### DeepSeek API

单次完整流程（笔记→出题→答题→评分）：
- Input: ~8000 tokens × $0.14/1M = $0.0011
- Output: ~2000 tokens × $0.28/1M = $0.00056
- **单次约 ¥0.012**

全班 20 人 × 50 次 = **约 ¥12**（讲师统一出 key 完全扛得住）

### 部署

Vercel 免费层足够，无需额外开销。

## 八、商业化路径（课堂收尾讲解用）

```
今天 (1.0):         前端 + DeepSeek API + localStorage
↓
明天 (2.0):         跨端封装 + 面试官模块
↓
未来升级方向:
  + Cloudflare Workers 代理 (隐藏 key，30 行)
  + Supabase Auth (登录注册，配置即用)
  + Supabase Postgres (跨设备同步)
  + Stripe / 微信支付 (订阅制 ¥9.9–¥19.9/月)
  + 上架 App Store / Google Play
```

## 九、悬念与伏笔设计

贯穿课程可以埋的"钩子"：

1. **"你的 Key 在浏览器里裸奔"** → 引出代理服务器必要性的悬念 → 商业化时解决
2. **"刷新就没了"** → 引出 localStorage → 未来引出云端同步
3. **"只能在电脑上看"** → 引出 Tauri → 现场打包 APK
4. **"AI 出的题太浅了"** → 引出 prompt engineering → 学生自己调 prompt
5. **"面试官怎么接入"** → 2.0 悬念，为第二天埋期待
