# 体验优化提示词 — 知识卡片滑动闯关

> 本提示词用于课堂第二环节，演示如何通过精准的提示词快速优化产品体验。

---

## 背景

当前 `KnowledgeCards.vue` 组件采用 2×3 网格布局，一屏展示所有卡片，点击翻转查看答案。

**体验问题**：
- 信息密度过高，用户注意力分散
- 缺乏"闯关"的游戏感和成就感
- 交互方式单一，不够有趣

---

## 优化目标

将知识卡片改造成**单卡滑动闯关模式**，参考 Tinder / Thread 的交互：

1. **一次只展示一张卡片**，聚焦单个知识点
2. **滑动交互**：
   - 向左滑 → "掌握了"（绿色提示）
   - 向右滑 → "没掌握"（橙色提示）
   - 滑动后卡片消失，自动展示下一张
3. **进度反馈**：顶部显示"3 / 12"进度条
4. **完成状态**：全部卡片学完后显示总结页

---

## 提示词（喂给 AI）

```
你是一个前端交互优化专家。我需要你重构 Vue 3 组件 `KnowledgeCards.vue`，将当前的"网格翻转卡片"改造成"单卡滑动闯关"模式。

当前实现：
- 2×3 网格布局，一屏展示所有卡片
- 点击卡片翻转查看正反面
- 用户需要手动点击"开始测试"进入下一步

目标交互（参考 Tinder / Thread）：
1. 一次只展示一张卡片（居中、大尺寸）
2. 支持滑动手势：
   - 向左滑 → 标记为"掌握了"（绿色边框提示）
   - 向右滑 → 标记为"没掌握"（橙色边框提示）
   - 滑动后卡片飞出屏幕，自动展示下一张
3. 顶部显示进度："已学习 3 / 12"
4. 全部卡片学完后显示总结页：
   - "🎉 全部学完了！"
   - 统计："掌握 8 张 / 待复习 4 张"
   - "开始测试"按钮（触发 @next 事件）

技术要求：
- 使用 Vue 3 Composition API
- 滑动手势用原生 touch 事件实现（touchstart / touchmove / touchend）
- 卡片飞出动画用 CSS transform + transition
- 保持现有的 Tailwind CSS 风格（琥珀色系）
- 保持 props 和 emits 接口不变：
  - props: { cards: Array, outline: Object }
  - emits: ['next']

UI 细节：
- 卡片尺寸：宽 90vw（最大 500px），高 60vh（最大 400px）
- 滑动阈值：横向位移 > 100px 触发飞出
- 飞出动画：300ms，配合旋转效果
- 进度条：顶部固定，琥珀色填充
- 总结页：居中卡片样式，白色背景

请直接输出完整的 `KnowledgeCards.vue` 组件代码，包含 <script setup>、<template>、<style scoped>。
```

## 使用方式（课堂演示）

### 第一步：展示当前版本的问题

打开 http://localhost:5173/，走到知识卡片页面，让学员看到：
- 一屏 6 张卡片，信息量大
- 点击翻转的交互

### 第二步：提出优化需求

口述："我们发现这个页面不够有趣，能不能改成像刷 Tinder 那样，一次只看一张卡，左滑右滑来标记掌握程度？"

### 第三步：使用优化提示词

把上面的提示词复制给 AI（Claude / ChatGPT / Cursor），让 AI 生成新的 `KnowledgeCards.vue` 代码。

### 第四步：替换组件代码

把 AI 生成的代码替换到 `src/components/KnowledgeCards.vue`，保存后页面自动刷新。

### 第五步：对比效果

刷新页面，走到知识卡片页面，展示新的滑动交互：
- 一次只显示一张卡片
- 左滑/右滑卡片飞出
- 进度条实时更新
- 学完后显示总结页

### 第六步：引出"问题左移"概念

**讲解要点**：
- 如果这个问题在上线后才被用户反馈 → 要重走"需求→开发→测试"全流程，可能需要 1-2 周
- 现在在开发阶段发现 → 只用一段 200 字的提示词 + 5 分钟，问题就解决了
- **这就是"问题左移"的价值**：越早发现问题，修正成本越低
- 提示词工程 = 用最少的 Token 解决最多的问题

## 预期效果

学员会直观感受到：
1. **提示词的威力**：一段话就能彻底改变产品交互
2. **迭代的速度**：从发现问题到解决，只需要几分钟
3. **AI 协作的价值**：不需要自己写复杂的手势识别代码，AI 全包了

---

## 注意事项

1. **提示词要足够具体**：交互细节、动画参数、UI 尺寸都要明确，否则 AI 会自由发挥
2. **保持接口一致**：props 和 emits 不变，确保上下游组件不受影响
3. **技术栈约束**：明确要求用 Vue 3 + Tailwind，避免 AI 引入新依赖
4. **课堂时间控制**：如果 AI 第一次生成的代码有 bug，准备一个备用版本，避免现场调试超时

## 扩展思考（课后作业）

让学员尝试用类似的提示词优化其他环节：
- 笔记输入页：能否加一个"示例笔记"按钮，点击自动填充？
- 出题页：能否加一个"跳过"按钮，跳过当前题目？
- 评分页：能否加一个"查看解析"按钮，展开知识点详解？

通过这些小优化，让学员理解：**好的提示词 = 精准的需求描述 + 明确的技术约束**。
