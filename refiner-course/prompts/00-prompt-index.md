# 练知 (Refiner) — 提示词索引

> 本文档说明 4 组提示词之间的关系、调用顺序与数据流转。
> 子代理在实现对应任务时，直接读取对应的 `.md` 文件获取完整提示词。

---

## 总数据流

```
                    P1                                P2
用户粘贴笔记 ──────────→ 结构化章节目录（JSON） ──────────→ 知识卡片列表
                                                          │
                                                          │ P3
                                                          ▼
用户答题 ──── P4 ←──── 练习题（选择/判断/简答） ←─────┘
```

---

## 各文件职责

| 文件 | 步骤 | 输入 | 输出 | 调用时机 | 用户等待 |
|------|------|------|------|----------|----------|
| `01-notes-structurer.md` | P1 | 用户粘贴的原始笔记文本 | 结构化大纲 JSON（章节+知识点） | 用户点击"开始学习" | 3–8秒 |
| `02-knowledge-cards.md` | P2 | 结构化大纲 JSON | 知识卡片列表 JSON | P1 完成后后台批量调用 | 2–5秒 × N张 |
| `03-quiz-generator.md` | P3 | 知识点列表 JSON | 练习题列表 JSON | 用户点击"开始测试" | 3–8秒 |
| `04-answer-evaluator.md` | P4 | 题目 JSON + 用户答案 | 评分+反馈 JSON | 用户提交答案 | 2–4秒 |

---

## 依赖关系

```
P1 ──必须串行──→ P2 ──独立任务──→ P3 ──每道题独立调用──→ P4
                      │
                      └── P3 也可单独调用（用户选中特定知识点出题）
```

- **P1 → P2**：必须先做笔记结构化，才能生成卡片（串行依赖）
- **P2 → P3**：知识卡片生成后，出题时直接读知识点列表（可后台预生成题库，也可按需调用）
- **P3 → P4**：先出题，用户作答后调用 P4 评分
- **P1/P2/P3 都是批量调用**：一次输入，多次输出
- **P4 是单次调用**：一问一答

---

## 调用策略建议

```
// 伪代码示意

// 加载页面时
const outline = await callLLM(P1, rawNotes)
const cards = await Promise.all(outline.chapters.flatMap(c =>
  c.knowledgePoints.map(kp => callLLM(P2, kp))
))

// 用户点击"开始测试"
const quiz = await callLLM(P3, selectedKPs)

// 用户提交答案
const result = await callLLM(P4, { question, userAnswer })
```
